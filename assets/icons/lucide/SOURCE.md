# Lucide thin weather symbols

Pinned source: https://github.com/lucide-icons/lucide/tree/1ef60af944de207e0d5176905a0759ba12e6ee8d

Original SVGs are unchanged. LICENSE preserves Lucide ISC and inherited Feather MIT notices. InkOS renders rounded outlines at 16/24/40/64 native pixels using 1/1/1.25/2 px target strokes and a single monochrome threshold. Heavy snow adds small flake crosses. No runtime scaling, grey antialiasing or image generation is used.
