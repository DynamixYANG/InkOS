# 当前边界与后续方向

以下是扩展方向，不代表已经实现，也没有承诺交付日期。

## 当前已经实现

七页、本地与双世界时钟、芬兰节日、天气双来源、ICS 只读订阅、Spotify PKCE 接入路径、同步歌词渲染、月相与太阳计算、FI 电价与三项成本配置、ShadUI Studio、设备本地诊断、保守刷新策略。

## 优先验证

- 用户自己的 Google Calendar 私密 ICS 订阅与真实重复事项。
- 用户自己的 Spotify Developer app、授权及活动播放。
- 新布局的长时间实体屏幕清晰度，特别是低温与频繁歌词局刷。
- 长标题／地点、跨日与夏令时周、多个来源冲突的实物可读性。

## 可能的功能扩展

- 更大的 Unicode／CJK 字库，按内容或语言拆分字体资源。
- 更丰富的日历周导航、事项溢出浏览与更高容量，但保持 PSRAM 和网络负载有界。
- 私有 CalDAV、Google Calendar OAuth、Microsoft Graph，使用独立 provider 和专用凭据存储。
- Studio 内整合 Wi-Fi 配置，减少首次配网对 Python helper 的依赖。
- 邮件若后续需要单独接入，应定义未读数／标题／摘要、权限和凭据边界；目前没有邮件读取功能。
- 更多地区电价和合同费用模型；各源先统一单位，再渲染。
- 有 schema 迁移、签名校验和双槽回滚设计的 OTA；当前没有可直接使用的 OTA 分区。

## 不应回退的约定

不为高 FPS 恢复已造成变淡的实验短波形；不把网络抓取搬到 renderer；不把密码写进源码或公开示例；不以零值代替缺失天气／电价；不将历史或合成测试写成当前真实账号验证。
