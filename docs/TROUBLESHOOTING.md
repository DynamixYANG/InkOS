# 故障排查

## 串口和烧录

**没有端口**：确认 USB 线能传数据、主控有供电、驱动正常，再检查系统设备管理器。下载模式可能枚举成另一个端口。

**打开失败／被占用**：关闭 Studio、Python helper 和串口监视器。三个工具不能同时独占同一个串口。

**握手无响应**：按住 BOOT、短按 RESET、松开 BOOT，再 inspect。核对返回 MAC，不能靠端口号猜设备身份。

**烧录后仍在下载模式**：只短按 RESET，不按 BOOT。程序启动先做清屏，等待约 8 秒，不要在这段时间反复断电。

**分区拒绝**：先检查是不是拿到了其他固件、默认 partitions 或 merged 镜像。不要删除保护或改写 NVS 来绕过错误。

## 屏幕

**BUSY 一直不就绪**：先断电检查排线方向、接插件、锁扣、驱动供电与控制器。BUSY 低表示忙，不应通过反转代码盲试修复连接。

**白底黑字反过来**：检查内部 bit polarity 与 PBM 导出是否混淆。内部 1 白 0 黑；PBM 导出单独反转。不要在多层重复取反。

**静态字淡、背景脏**：关闭 Frequent Home updates，回主页或重新启动触发全刷，观察静置后的均匀性。当前工厂波形策略是已获得正向反馈的基线，不要重新加入历史短 LUT。

**快刷不够快**：局刷约 1.1 秒本来就无法保证每 0.5 秒完成。网络事件与动画帧合并，不会无限排队。需要快速运动的交互不适合用本面板强求。

## 网络与数据

**OFFLINE**：确认 2.4 GHz 网络、密码、路由器连接和供电。用临时 helper 更新 Wi-Fi 后关闭它。设备先联网再 SNTP，未有有效时间时不会做正常外部数据抓取。

**TLS／接口失败**：先检查时间和网络，再看非敏感 HTTP 状态与重试；不要通过 setInsecure 跳过证书检查。天气失败保留上次数据。

**切换来源后没立刻变**：保存设置后等待请求、解析和面板刷新。MET 的某些字段缺失是正常未知值，不应由旧来源数值补造。

## 日历

**空日程**：确认启用开关、完整 ICS URL、目标日历确有本周／未来事件；网页分享链接不等于 ICS 链接。设备不是 Gmail 收件箱读取器。

**Google 私密地址找不到**：核对是否选中了正确的具体日历和 Google 账号。组织账号可能隐藏该功能；只读公开地址只有日历已经公开时才适用。不要为了绕过问题误公开私人日历。

**时间偏移**：核对本地时区与 ICS 的 TZID；28 项目录以外的时区或复杂规则可能报错。全天日期与 UTC 时间不是同一种语义。

**少于全部事件**：当前容量 96 条、35 天窗口，Week 每天只显示前两条并标记额外数量；未知规则和超限会显示错误或保留旧缓存。

## Spotify

先读 [Spotify 指南](SPOTIFY.md)。最常见的是 Redirect URI 8767/8768 混用、账号不在 allowlist、没有活动播放、授权被撤销，以及歌曲版本在 LRCLIB 中不匹配。Client Secret 不属于本流程。

## 电价

**总价偏高／重复含税**：核对来源单位、spot 是否未含税，以及两项费用是否已含 VAT。默认是费用未含税，不能再把源的 gross 当 net。

**未来空柱**：未发布或缺少四个完整季度数据时应保持缺口，不是显示故障。当前小时有黑色标签，前后各 12 个经过小时；跨午夜看日期，不只看小时数字。

**当前显示 --**：检查时间有效性、Energy 开关、当小时数据与缓存状态。不要把未知价格显示成零价。
